다운받아 바로 실행

압축을 풀거나 Python을 설치하지 않아도 됩니다. AI 대화에는 Ollama가 필요합니다.

Ollama 다운로드 ↗
  1. Zero.exe를 내려받습니다.
  2. 다운받은 Zero.exe를 실행합니다. 음성 입력 시 마이크 권한을 허용하세요.
  3. Ollama 설치 후 명령 프롬프트에서 ollama pull qwen3.5:2b를 한 번 실행하면 AI 대화를 사용할 수 있습니다.

기존 ZIP 버전에서 옮기는 경우 새 Zero.exe를 한 번 직접 실행하세요. 이후 업데이트는 앱 안에서 EXE 파일을 선택하면 됩니다. 처음 AI 모델을 받을 때 인터넷 연결과 수 GB의 여유 공간이 필요합니다.
