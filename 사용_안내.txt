제로 Windows 앱

업데이트
- 새 버전의 Zero_App.zip을 받은 뒤 제로에서 [↻ 업데이트]를 누릅니다.
- ZIP 파일을 선택하고 설치를 확인하면 제로가 업데이트 후 다시 시작됩니다.
- 업데이트 파일을 적용하려면 앱 폴더에 쓰기 권한이 있어야 합니다.

실행
1. Zero 앱 ZIP의 압축을 풉니다.
2. Zero.exe를 실행합니다. Python 설치는 필요하지 않습니다.

로컬 AI 대화
- Ollama가 설치되어 실행 중이어야 합니다.
- 모델이 없다면 명령 프롬프트에서 `ollama pull qwen3.5:2b`를 한 번 실행합니다.
- 처음 모델을 받으려면 인터넷 연결과 수 GB의 저장 공간이 필요합니다.

음성 명령
- [말하기]를 누른 뒤 말합니다. 한국어 음성 인식 모델은 앱에 포함되어 있습니다.
- 마이크 입력에는 Windows 마이크 권한이 필요합니다.
- “지금 몇 시야”, “계산 5 더하기 3”, “크롬 켜줘”, “메모장 열어”, “계산기 실행해” 등을 사용할 수 있습니다.
- 일반 질문은 로컬 AI에 전달됩니다.

답변은 생성되는 대로 화면에 표시됩니다. Ollama 모델은 실행 후 10분 동안 메모리에 유지해 후속 질문을 빠르게 합니다.

대화 기록은 프로그램을 닫으면 초기화됩니다.
